# Reiatsu — Multi-Device Storage Intelligence & Retrieval

Reiatsu is an on-device local storage intelligence ecosystem designed for private, fast, and multi-device indexing and retrieval.

## Repository Roadmap
1. **MVP**: Mobile on-device indexing & chunking with local AI
2. **PC Port**: StorageSense Desktop (`pc_port/`) — Zero-cloud privacy, dual-tier autonomous retrieval, multi-modal deduplication & smart space reclamation
3. **Mobile-to-Mobile Transfer**: Direct peer-to-peer transfer
4. **Inter-connected NAS**: Network storage integration
5. **Fully Connected Mesh**: PC, Laptop, NAS, and mobile device synchrony

---

## 🚀 PC Port Quickstart (`pc_port/`)

### 1-Click Launch
Double-click `Start_StorageSense.bat` in the repository root or inside `pc_port/` to launch the graphical Web Dashboard at `http://localhost:8501`.

### CLI Assistant
Double-click `StorageSense_Assistant.bat` or run:
```powershell
cd pc_port
py run_cli.py
```
