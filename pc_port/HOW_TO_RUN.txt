========================================================================
             StorageSense PC Port — How to Run (1-Click Launchers)
========================================================================

You do NOT need to type commands in a terminal. StorageSense includes a
compiled native Windows executable (.exe) and 1-click launchers:

------------------------------------------------------------------------
Option 1: Native Windows Executable (Recommended!)
------------------------------------------------------------------------
Double-click:
   👉 StorageSense.exe

What it does:
- Starts the StorageSense local intelligence engine quietly in the background.
- Opens a dedicated **Native Desktop Application Window** (Chromium / Edge
  App Mode) with no browser tabs or URL bars — feels 100% like a native desktop app!
- Puts a StorageSense icon in your Windows System Tray (near the clock) where
  you can:
    • Open Dashboard anytime
    • View real-time logs
    • Restart the server
    • Cleanly exit (kills background server automatically via Win32 Job Object)

------------------------------------------------------------------------
Option 2: Windows Desktop Shortcut
------------------------------------------------------------------------
Double-click:
   👉 Create_Desktop_Shortcut.bat

An official "StorageSense" desktop shortcut with the application icon will
be created on your Windows Desktop. Double-click it anytime from your desktop!

------------------------------------------------------------------------
Option 3: Browser Batch Launcher
------------------------------------------------------------------------
Double-click:
   👉 Start_StorageSense.bat

Starts the server and opens StorageSense in your default browser tab.

------------------------------------------------------------------------
Option 4: Interactive CLI Terminal Assistant
------------------------------------------------------------------------
If you prefer a fast, numbered terminal menu without opening a browser:
Double-click:
   👉 StorageSense_Assistant.bat

Menu Options:
   [1] Open Desktop Dashboard (Web UI in Browser)
   [2] View Live System Telemetry (RAM, Drive, Ollama status)
   [3] Scan & Index a Folder
   [4] Search Files with AI Synthesis
   [5] Scan for Duplicate Files (Exact, Semantic & Images)
   [6] Propose Space Cleanup
   [7] Exit

------------------------------------------------------------------------
Developer & Build Tools:
------------------------------------------------------------------------
- Recompile Executable:   python build_exe.py  (or run build_exe.bat)
- Package Release ZIP:    python package_release.py
- Command-Line Usage:     python run_cli.py --search "your query"
